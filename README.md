# 우리 마을 이장님

초등 3학년 사회(아이스크림 교과서) 흐름을 따라 마을을 가꾸며 배우는 심시티형 게임이에요.
쉬는 시간에 혼자 할 수 있도록 만들었어요. 게임이 80%, 공부가 20%예요.

- `index.html` : 게임
- `admin.html` : 선생님 관리실 (자랑 게시판 숨기기·지우기, 선생님께 말하기 읽기)
- `firebase-config.js` : Firebase 설정값 (비워 두면 기기 저장 모드)
- `firestore.rules` : Firebase 보안 규칙
- `assets/` : 그림

---

## 1. GitHub Pages로 올리기

1. GitHub에서 새 저장소를 만들어요. 예: `ijang`
2. 이 폴더 안의 파일을 모두 올려요(폴더째가 아니라 안의 파일들). `.nojekyll` 파일도 같이 올려요.
3. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 정하고 저장해요.
4. 1~2분 뒤 `https://아이디.github.io/ijang/` 주소로 열려요.

이 단계까지만 해도 게임은 돌아가요. 이때는 **이 기기에만 저장**되고, 자랑하기는 꺼져 있어요.

---

## 2. Firebase 연결하기 (자랑 게시판 · 아이디로 이어 하기 · 선생님께 말하기)

### 2-1. 프로젝트 만들기
1. https://console.firebase.google.com 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 돼요)
2. 요금제는 무료(Spark) 그대로 둬요. Storage는 쓰지 않아요.

### 2-2. 웹 앱 등록 → 설정값 복사
1. 프로젝트 개요 옆 톱니바퀴 → **프로젝트 설정** → 내 앱 → **웹(</>)** 추가
2. 나오는 `firebaseConfig = { ... }` 값을 `firebase-config.js`의 `window.FIREBASE_CONFIG = { ... };` 에 붙여 넣어요.

### 2-3. 로그인 방법 켜기 (Authentication)
1. **Authentication → 시작하기 → 로그인 방법**
2. **익명** 사용 설정 → 아이들은 아무것도 입력하지 않아도 돼요.
3. **Google** 사용 설정 → 관리실(`admin.html`)은 선생님 Google 계정으로 들어가요.
4. **Settings → 승인된 도메인**에 `아이디.github.io` 를 추가해요.

### 2-4. Firestore 만들기
1. **Firestore Database → 데이터베이스 만들기** → 위치는 `asia-northeast3 (서울)` → 프로덕션 모드
2. **규칙** 탭에 `firestore.rules` 내용을 통째로 붙여 넣고 **게시**해요. (관리자 이메일은 규칙 안의 `isAdmin()` 에 적혀 있어요.)

### 2-5. 오래된 자랑 지우기
무료 요금제(Spark)에서는 Firestore 자동 삭제(TTL)를 쓸 수 없어요. 7일이 지난 자랑은 게임에서 자동으로 안 보이고, 가끔 `admin.html` → **오래된 자랑 청소** 버튼으로 14일 지난 자랑을 지워 주세요.

(참고: 유료 요금제로 바꾸면 아래처럼 TTL을 쓸 수 있어요.)
1. Firestore → **TTL 정책**(Time-to-live) → 정책 만들기
2. 컬렉션 그룹 `boast`, 필드 `expireAt` 으로 하나, `cheers`, `expireAt` 으로 하나 더 만들어요.
3. 자랑은 7일 동안 게임에 전시되고, 14일이 지나면 자동으로 지워져요. (8~14일째 자랑 중 응원을 많이 받은 3개는 "지난주 인기 마을"로 한 번 더 보여요.)
4. TTL을 못 쓰는 경우에는 `admin.html` → **오래된 자랑 청소** 버튼으로 지울 수 있어요.

### 2-6. 확인
- 게임 첫 화면에서 "처음 왔어요"로 아이디를 만들고 → 📸 자랑 → 학교·학년·별명 입력 → 자랑 문장 고르기 → 올리기
- `admin.html` 에 관리자 Google 계정으로 들어가 올라온 자랑이 보이면 끝!

## 자랑 게시판 규칙 (아이들에게 안내)
- 마을 전체 사진 + 정해진 자랑 문장(최대 3개)만 올라가요. 자유 글은 없어요.
- 학교·학년·**별명**만 보여요. 실제 이름은 쓰지 않아요.
- 하루에 한 번 올릴 수 있고, 일주일 동안 전시돼요.
- 응원은 👏 멋져요 · ❤️ 살고 싶어요 · 🌟 최고예요 스티커로만 보내요.
- 내 자랑은 내가 올린 기기에서 내릴 수 있어요. 이상한 게시물은 선생님이 관리실에서 숨기거나 지워요.

## 무료 사용량 참고 (Spark)
- 저장 1GB, 하루 읽기 5만 번, 쓰기 2만 번
- 자랑 사진 1장은 약 100~200KB라 동시에 수천 장까지 들어가요.
